# 按任务类型的补充清单

只读当前任务对应的小节，把适用项写进交接包。查不到但会影响接手的，加入询问清单。

## 代码 / 架构开发

- 仓库根、分支、HEAD、未提交与未跟踪文件、stash、与远端差距
- 运行时版本、包管理器、锁文件、安装命令
- 启动、构建、测试、lint、类型检查命令及最近结果
- 入口、核心模块、数据流、外部依赖、API 契约
- 数据库 / schema / 迁移、feature flag、部署状态
- 已知报错、日志位置、复现步骤
- 密钥与凭据的位置（只写变量名或配置文件）
- 未完成的重构、临时补丁、TODO
- 下一个改动的验收方式（自动测试或手动步骤）

询问：本地是否有未推送修改、特殊环境变量、私有依赖或无法自动安装的工具。

## 论文 / 科研 / 实验

- 研究问题、假设、当前结论与置信度
- 数据集 / 版本 / 划分 / 预处理
- 模型与超参数、随机种子、框架版本
- 硬件与算力约束、单次运行时长
- 已跑通的 benchmark 与指标（原始数字、统计口径）
- 已否定的假设及原因
- 图表、表格、附录状态
- 引用库、目标期刊、格式要求
- 写作进度与待补实验
- 可复现命令

询问：是否有未写入对话的实验结果、指标口径、导师或审稿人的硬约束。

## 多 agent / 工作流

- 各角色职责与边界
- 消息 / 任务 schema、状态机、超时与重试策略
- 工具与 MCP 服务清单、权限、鉴权位置
- 长任务、队列、定时任务当前状态
- 人工审批点
- 已知失败模式与降级策略
- 记忆或状态存放位置

询问：新 agent 需要继承哪些权限、哪些操作必须人类批准。

## 长文 / 剧本 / 策划

- 核心命题、目标读者、交付格式与字数
- 已定稿大纲与各章节状态
- 世界观、角色卡、术语表、时间线
- 风格指南与禁用手法
- 已发现的前后矛盾、伏笔清单
- 各版本草稿与权威版本
- 下一步是续写、改写还是统稿
- 已废弃的情节与设定

询问：接下来是续写还是润色、哪些设定不可改。

## 运维 / 部署

- 环境清单与访问方式（不含密钥）
- IaC、配置、镜像版本
- 备份与回滚步骤
- 监控、告警、日志位置
- 当前事故、变更冻结
- 权限归属与联系人
- 最近一次变更及结果

询问：是否有正在进行的变更、谁有权批准上线。

## 通用补充

- 截止时间、干系人、预算、合规与隐私要求
- 外部依赖与等待项
- 用户明确说过的“不要做”
